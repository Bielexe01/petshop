# Fotos da Clínica

Coloque aqui as fotos reais da clínica. A página usa as fotos automaticamente assim que os arquivos forem adicionados — enquanto não existirem, aparecem os **placeholders de marca** (bloco colorido com o nome da seção), então a página nunca quebra.

## Nomes de arquivo esperados

| Arquivo | Uso |
|---|---|
| `fachada.jpg` | Fachada da clínica (hero e seção "A Clínica") |
| `fachada-2.jpg` | Fachada secundária (StoryScroller) |
| `equipe.jpg` | Equipe (seção Equipe) |
| `equipe-2.jpg` | Equipe em atendimento (StoryScroller) |
| `atendimento.jpg` | Atendimento veterinário (seção Equipe) |
| `animais.jpg` | Animais (seção Estrutura / StoryScroller) |
| `ambiente.jpg` | Ambiente interno / estrutura |
| `doutora.jpg` | Dr.ª Cássia Carvalho (destaque da Equipe) |
| `recepcao.jpg` | Recepção (seção Estrutura) |
| `pet-thor.jpg` | Pet de demonstração — Thor |
| `pet-luna.jpg` | Pet de demonstração — Luna |

## Formato

- **JPG ou PNG**, de preferência **JPG**.
- **Tamanho sugerido**: 1600 px na maior dimensão (comprimidas ~150–400 KB) — mantém a landing rápida.
- Orientação: retrato ou paisagem conforme o uso acima.

## Como adicionar

Basta copiar os arquivos para esta pasta. O sistema relê a lista de arquivos ao carregar a página — não precisa reiniciar o servidor para fotos novas aparecerem (apenas recarregar).

> Dica: se preferir trocar uma foto por outra, mantenha o mesmo nome de arquivo que a página continua funcionando sem editar código.
